## 📖 Project Description

The Student Profile Management System is a Java-based web application developed to manage student profile information through a web browser.

The system allows users to add, view, search, edit and delete student profiles. It also provides filtering options to make finding specific student information easier.

## ✨ Features

- **➕ Add Profile** – Register new student profiles with personal and academic information.
- **🔍 Search Profile** – Search for student profiles using Student ID or Name.
- **✏️ Edit Profile** – Update existing student profile information.
- **🗑️ Delete Profile** – Remove student profiles from the database.
- **🔎 Filter Profiles** – Filter student records by Programme and Hobbies.
- **👤 View Profile** – Display individual student profile information.

## 🚀 How to Run

1. Install and open **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Open **NetBeans IDE**.
4. Select **File → Open Project**.
5. Locate and open the `PersonalProfile_2` project folder.
6. Make sure the MySQL database `StudentProfilesDB` and the required `Profile` table have been created.
7. Check the database connection settings in `DBConnection.java`.
8. Configure **Apache Tomcat** as the application server.
9. Right-click the project and select **Run**.
10. The application will open in your web browser.

## 🗄️ Database Configuration

The application uses MySQL to store student profile information.

**Database Name:** `StudentProfilesDB`

**Table Name:** `Profile`

| Column | Description |
|---|---|
| studentID | Student identification number |
| name | Student name |
| programme | Student programme |
| email | Student email address |
| hobbies | Student hobbies |
| introduction | Personal introduction |

Make sure the database and table are created before running the application.
